# Garden Glory

A tiny idle/clicker garden game in a single HTML file. Open `index.html` in any browser to play. No installs, no servers.

## New in this build

- **Hell Mode** — clear the normal stages first, then brave the Hell levels. Each Hell level ends in a **Hell Boss**, and the whole screen turns blood-red with runes and skeletons while you're in the Underworld.
- **🪄 Enchanter** (opens **Sep 26**) — spend Enchanting Shards to evolve plants. Their level resets but they keep +35% power permanently.
- **Events page** — monthly quests, streak rewards, and a daily gift calendar.
- Big visual overhaul across map, lab, hub, and title.

## Files

- `index.html` — the whole game.
- `garden-glory.js` — the same game as a single JS file if you want to embed or repack it.
